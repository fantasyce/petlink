PetLink

安装：将 PetLink.app 拖到 Applications，随后从“应用程序”打开。
需要 macOS 13 或更新版本。请选择适合自己电脑的 Apple Silicon 或 Intel 安装包。
语言：设置 → 语言，可选跟随系统、简体中文或 English，立即生效。
本地会话自动识别；登录 Google 后可添加好友、串门和开启加密 Agent 聊天。
只有点击聊天授权后才会读取或准备本机钥匙串中的密钥。
许可证保存在 PetLink.app/Contents/Resources/Licenses；字体许可保存在 Resources/OFL-Yozai.txt。
当前为本地测试签名版本，尚未完成 Apple Developer ID 签名与公证。

Install: drag PetLink.app to Applications, then open it from Applications.
Requires macOS 13 or later. Choose the Apple Silicon or Intel package for your Mac.
Language: Settings → Language. Choose Follow system, 简体中文 or English; changes apply immediately.
Local Agent sessions are detected automatically. Sign in with Google to add friends,
visit their pets and enable encrypted Agent chat.
Chat keys are read or prepared in this Mac's Keychain only after you authorize chat.
Licenses: PetLink.app/Contents/Resources/Licenses. Font license: Resources/OFL-Yozai.txt.
This build uses a local test signature; Apple Developer ID signing and notarization are pending.
